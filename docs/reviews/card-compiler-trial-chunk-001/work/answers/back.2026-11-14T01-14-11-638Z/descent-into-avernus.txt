At the beginning of your upkeep, put two descent counters on this enchantment. Then create a number of Treasure tokens equal to the number of descent counters on this enchantment. Each Treasure token is an artifact token (its type line is hidden), with no colors and no power or toughness, and it has "{T}, Sacrifice this token: Add one mana of any color." Each opponent creates the same number of Treasure tokens, with the same description, as you do. Then this enchantment deals damage equal to the number of descent counters on it to each player. This trigger is mandatory and has no targets.
